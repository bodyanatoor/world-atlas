# Аверн · Мерран · Каморі

Готовий статичний сайт атласу v2.0. Збірка та встановлення бібліотек не потрібні.

## Публікація через GitHub Pages

1. Створіть новий Public-репозиторій, наприклад `world-atlas`. Увімкніть Add a README file, щоб одразу отримати гілку main.
2. Розпакуйте ZIP. У репозиторії виберіть Add file → Upload files.
3. Перетягніть ВМІСТ розпакованої папки: index.html, папки assets і data, README.md. Збережіть вкладені папки. index.html має бути в корені репозиторію, а не всередині додаткової папки site чи world-atlas. Сам ZIP завантажувати не потрібно.
4. Натисніть Commit changes.
5. Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.
6. Дочекайтеся завершення публікації. Для bodyanatoor/world-atlas адреса буде https://bodyanatoor.github.io/world-atlas/.

`.nojekyll` включений у ZIP, але може бути прихований у Finder. Цей сайт не потребує спеціальної обробки Jekyll і використовує звичайні імена папок; пропуск прихованого файлу під час завантаження не змінює структуру ресурсів.

Документація GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Що збережено та змінено

Усі дані світу й SVG п’яти карт побайтово/структурно звірені з затвердженим HTML v2.0. Географія, поселення, кордони, ліси й відстані не змінені.
Додаткові карти завантажуються після вибору та кешуються до закриття сторінки. Початковий обсяг файлів близько 3,23 МБ замість 7,89 МБ (без урахування стиснення сервером).
Переміщення використовує початкову позицію жесту. Оновлення кадрів об’єднані, підписи перераховуються після паузи, масштабування враховує величину прокручування. Є повідомлення про помилку завантаження.

Перевірено синтаксис, п’ять аркушів, приклади пошуку, три типи маршрутів, шари та математичну модель переміщення в ізольованій моделі DOM. Перевірка у справжньому браузері після публікації ще потрібна; виправлення не є гарантією усунення всіх можливих збоїв пристрою.

Сайт завантажує JSON і SVG через HTTP(S), тому для перевірки використовуйте адресу GitHub Pages: подвійне натискання index.html на комп’ютері не є підтримуваним запуском цієї версії.

## Редагування

- index.html — сторінка та її текст.
- assets/styles.css — оформлення.
- assets/app.js — керування атласом.
- assets/maps/*.svg — точна графіка п’яти аркушів.
- data/atlas.json — координати, довідкові дані та маршрути.

Зміни географії треба узгоджено вносити і в дані, і в графіку карт. Зміна лише SVG не пересуває координат пошуку та вимірювань.
