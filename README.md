# Аверн · Мерран · Каморі — атлас v2.1

32 аркуші, 469 записів довідника. Статичний сайт для GitHub Pages, без збірки та зовнішніх бібліотек.

## Оновлення наявного сайту

Розпакуйте `world-atlas-v2.1-update.zip`. У репозиторії відкрийте Add file → Upload files і перетягніть index.html, README.md, папки assets та data з архіву. Натисніть Commit changes. Папки містять лише оновлені файли; решту наявних файлів залиште. Дочекайтеся зеленого статусу публікації в Actions. Оновіть сайт комбінацією ⌘⇧R.

Повний архів `world-atlas-v2.1-full.zip` містить усі ресурси для нового репозиторію. index.html має бути в корені. Налаштування: Settings → Pages → Deploy from a branch → main → /(root).

## Нові можливості

- П’ять основних аркушів, дванадцять регіональних видів та п’ятнадцять провінцій Раверну.
- Картки міст, річок, лісів, природних зон, озер, гір, держав, провінцій, островів, історичних місць та маршрутів.
- Пошук по всьому довіднику. Вибір за геометрією та підписами. Допуск кліку 11 екранних пікселів для точок і ліній.
- Підсвічування об’єкта й список об’єктів у тій самій точці.
- Повернення до попередніх видів, лінійка, клавіатурне керування, жести двома пальцями.
- Під час руху використовується готове зображення карти на Canvas; після паузи оригінальна векторна карта знову відображається з потрібною деталізацією. При швидкому масштабуванні тимчасова м’якість зображення нормальна. На дуже довгому перетягуванні частина ще не перемальованого виду може тимчасово бути порожньою до відпускання миші.

## Географія та довідка

`data/atlas.json` і всі п’ять вихідних SVG не змінені. Нові регіональні аркуші — види тих самих координат, не додавання невідомих вулиць чи приток. Довідник побудований з наявних даних. Населення, водопостачання, лісистість і час подорожей зберігають позначки авторських припущень. Відсутню історію не вигадано.

Перша частина рукопису містить нові сюжетні відомості, але вони не вносилися автоматично до канону карти: окремо треба узгодити розбіжності назв і статусів.

## Перевірки

Пройдено 1800 перевірок проєкції, зміни масштабу та переміщення; звірено 176 координат поселень, межі 32 аркушів, вибір прихованих шарів, русел і територій з внутрішніми отворами. Ізольована модель інтерфейсу перевірила завантаження, пошук, картки, лінійку та відсутність повторного декодування SVG під час 120 подій перетягування та 50 подій колеса.

Це перевірки коду й моделі взаємодії, не вимірювання FPS у реальному браузері. Реальне відображення Canvas, шрифти, сенсорні жести й швидкодію потрібно перевірити на опублікованому сайті.

## Файли

- `index.html` — інтерфейс.
- `assets/app.js` — керування, відображення, картки.
- `assets/map-core.mjs` — координати, масштаб, геометрія вибору.
- `assets/styles.css` — оформлення.
- `data/catalog.json` — довідник та список аркушів.
- `data/atlas.json`, `assets/maps/*.svg` — збережені дані й оригінальна картографія.

Відкривати через GitHub Pages або звичайний HTTP-сервер. Подвійний клік по локальному HTML не підтримується, бо браузер обмежує завантаження окремих даних.
